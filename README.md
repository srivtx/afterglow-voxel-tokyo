# Afterglow · Voxel Tokyo

Interactive voxel recreation of *Tokyo Sunset: Pagoda and Neon Skyline*, built with Three.js. The site lives in [`web/`](web/README.md).

**Live:** https://srivtx.github.io/afterglow-voxel-tokyo/ (deployed from `web/` on every push to `main`).

```bash
python3 -m http.server 5180 --directory web
```
